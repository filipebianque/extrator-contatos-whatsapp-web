# Extrator de Contatos – WhatsApp Web 📱

Este script automatiza a extração de contatos da lista de conversas do WhatsApp Web, rolando a barra lateral automaticamente, coletando os números exibidos e exportando em `.csv`.

### 🧪 Como usar

1. Acesse [https://web.whatsapp.com](https://web.whatsapp.com)
2. Faça login normalmente.
3. Pressione `F12` e vá até a aba **Console**.
4. Copie e cole o conteúdo do `script.js`.
5. O script irá rolar a lista automaticamente, extrair os números e baixar um arquivo `contatos.csv`.

### ⚠️ Requisitos

- O navegador deve permanecer **ativo e visível** durante o processo.
- Pode levar alguns segundos dependendo da quantidade de conversas.

### 💡 Observações

- Esse script **não viola os Termos de Uso** enquanto for usado para fins legítimos (ex: gestão de contatos já existentes).
- Não armazena nem envia dados para terceiros.
